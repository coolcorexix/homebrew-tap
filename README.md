# coolcorexix/homebrew-tap

Homebrew tap for [**claude-grep**](https://github.com/coolcorexix/claude-grep) — full-text search over your Claude Code conversation history, with one-keypress resume.

## Install

```sh
brew install coolcorexix/tap/claude-grep
```

Then run `ccfind`.

> Requires Anthropic's Claude Code CLI (`claude`) on your `PATH`. `fzf`, `ripgrep`, and Python are installed automatically.
